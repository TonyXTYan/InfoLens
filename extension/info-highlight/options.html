Cloud credits

  • Full-speed cloud analysis uses credits. When you have no credits left, analysis automatically switches to the free API, which is rate-limited.
  • Cloud analysis is billed by usage in points. One point covers roughly one screen of text. Failed analyses are not charged; cached analyses are not charged.
  • To avoid waste, analysis pauses after about 32 points on the same page. Tap "Continue" to analyze more.
  • Credits need no account; your API key is your balance account—keep it safe.
