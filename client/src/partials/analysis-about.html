About / 关于

Info Highlight is a Chrome extension and a web tool that shows which words in a text carry more information. A language model reads the text from left to right and scores each token by surprisal: the information content, in bits, of that token given the tokens before it. Those scores are drawn as a heatmap. Darker tokens are less predictable from context and are worth reading carefully; lighter tokens are easier to guess and can be skimmed.

That picture matches a standard idea in psycholinguistics: the less predictable a word is from its context, the longer readers tend to dwell on it. Info Highlight uses the same quantity as a reading aid. Linger on the dark, informative words; skim the light, predictable ones.

A short example: in 「打开门看见了一只飞碟」, the surprising object is 飞碟 (a flying saucer). In 「打开门看见了一只猫」, the object 猫 (a cat) is much more predictable, so it should score lower.

How to use it

On this page, paste text or pick a demo and press Analyze. The heatmap appears in the panel on the right. To highlight a web page or a PDF you are already reading, install the Chrome extension and click the toolbar icon; click again to clear.

Local analysis in the extension runs on this device with WebGPU. That path is free, and the page text stays on your machine. Cloud analysis is optional and uses credits (1,000 credits ¥10 / $2; 3,000 ¥24 / $5; 10,000 ¥70 / $12, valid 12 months from purchase).

FAQ

Is it free? On-device WebGPU analysis is free. Cloud analysis uses credits. This website sends text to the analysis API.

Does my text leave my machine? On-device analysis in the extension does not upload text. Cloud analysis and this web page send text to the author’s servers to compute scores; the privacy policy says that text is not stored after the result is returned.

Which model? The extension’s on-device engine uses Gemma 3 270M (WebGPU). Cloud options include Qwen3 0.6B and Gemma 3 270M. This website uses open-source Qwen3-Base models (0.6B / 1.7B / 4B / 14B).

Does it work on PDF? The Chrome extension can highlight PDFs. For a local file, allow access to file URLs in the extension settings. This web page analyzes pasted text.
