Privacy Policy for Semantic Highlight

Last updated: September 2026

This extension and its backend are operated by Qingyun Dong, an individual developer (“the author”).

Data processed

When you search a webpage or PDF (toolbar icon, Ctrl+Shift+F / Command+Shift+F, or the page context menu), the extension sends two things to the backend server at api.info-lens.app:

  • The search query you type (or the selected text, if you started from the context menu)
  • The visible text of the article/body content of the page you are currently viewing

This data is sent only when you actively invoke the extension on the page you are viewing at that moment. The extension does not run in the background and does not access any other tabs or pages.

Separately, and without page content: the author uses an anonymous client id (a random UUID). It is stored as a first-party cookie on info-lens.app (shared with the Info Lens website and other Info Lens extensions) and cached in the extension’s local storage. Installing, updating, uninstall events, and optional survey answers may include this id together with the extension id and version. If you submit the uninstall survey, the author receives the reasons and comment you typed. The id is not linked to your name, email, or Google account. If you tap the in-product report button, the author receives the error text, current page URL, query, extension version, and browser user agent.

How it is used

The query and page text are used solely to compute semantic similarity and matching words, which the extension then highlights on the page. Version events, optional reports, optional survey answers, and the anonymous client id are used only to operate and improve the product. No other use is made of this data.

Data not collected

The author does not collect or store: names, email addresses, passwords, financial information, health information, personal communications, or any other personally identifiable information. The author does not track your browsing history across pages or sessions.

Data Storage & Retention

  • Query text and page content are processed to generate search results. The author does not keep them on the backend server after the response is returned.
  • Optional error reports and uninstall-survey answers are stored so the author can diagnose issues and improve the product. Install/update/uninstall events may store the extension id, version, and anonymous client id.
  • Your recent search queries and a local analysis cache are saved in your browser (via the extension's local storage) so searches can be reused. You can clear the cache from the options page. Clearing site data for info-lens.app resets the anonymous client id cookie.

Third-Party Sharing

To compute matches, the backend forwards the query and page text to OpenRouter, a language-model API, solely for that request. The author does not sell your data or use it for advertising.

Security

All data is transmitted over HTTPS.

Permissions

The extension requests the minimum permissions needed for its single purpose (semantic search on the active page):

  • activeTab / scripting: to read and highlight text on the page you are currently viewing, only when you invoke the extension
  • storage: to save your recent search queries and analysis cache locally in your browser
  • contextMenus: so you can start a search from the page's right-click menu

Optional host access is requested only for local PDF files (file://). The extension does not declare host permissions for the API. Query and page text are sent to the backend by the extension’s background service worker via a standard cross-origin HTTPS request; the page you are viewing never talks to the backend server directly.

Changes to This Policy

If the author's data practices change, the author will update this policy and the Chrome Web Store listing accordingly.
